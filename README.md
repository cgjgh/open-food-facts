# 🍏 Open Food Facts - Techy & Premium

A modern, high-performance web application designed to browse and contribute to the Open Food Facts database with a "Techy & Premium" aesthetic.

![Open Food Facts UI](https://img.shields.io/badge/UI-Glassmorphism-emerald?style=for-the-badge)
![Next.js](https://img.shields.io/badge/Next.js-16-black?style=for-the-badge&logo=next.js)
![Tailwind CSS](https://img.shields.io/badge/Tailwind-4.0-38bdf8?style=for-the-badge&logo=tailwind-css)

## ✨ Features

- **🚀 Scan-First Experience**: High-speed barcode scanning directly from your browser.
- **💎 Premium UI**: Deep glassmorphism effects, animated gradient-mesh backgrounds, and smooth micro-animations.
- **📊 Detailed Analytics**: In-depth product scoring (Nutri-Score, Eco-Score, NOVA) with visual breakdowns.
- **📜 Scan History**: Persistent local history of your scanned products.
- **📥 Easy Submissions**: Simple interface to add new products to the Open Food Facts database.
- **🌓 Adaptive Theme**: Sleek dark mode and light mode with frosted glass transitions.

## 🛠️ Tech Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS 4](https://tailwindcss.com/)
- **UI Components**: [Shadcn UI](https://ui.shadcn.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **API Client**: [@openfoodfacts/openfoodfacts-nodejs](https://github.com/openfoodfacts/openfoodfacts-nodejs)
- **Scanner**: [html5-qrcode](https://github.com/mebjas/html5-qrcode)
- **State Management**: React Hooks & Local Storage

## 🚀 Getting Started

### Prerequisites

- Node.js 18+ 
- npm / yarn / pnpm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/cgjgh/open-food-facts.git
   cd open-food-facts
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.
